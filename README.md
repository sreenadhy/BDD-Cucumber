# ✈️ BDD Cucumber Automation Framework (Selenium + Java + POM)

This project is a **Behavior Driven Development (BDD)** test automation framework built using:

- Java
- Selenium WebDriver
- Cucumber (BDD)
- Page Object Model (POM)
- Extent Reports

It automates end-to-end scenarios for a flight booking application (PHPTravels).

---

## 🚀 Features

✔ BDD implementation using Gherkin syntax  
✔ Page Object Model (POM) design pattern  
✔ Modular and scalable framework  
✔ Explicit waits for stability  
✔ JavaScript executor handling dynamic elements  
✔ Extent HTML Reports with screenshots  
✔ Reusable utilities and clean structure  

---

## 🧠 Scenarios Covered

### 🔐 Login
- Valid user login
- Authentication validation

### ✈️ Flight Booking
- Search flights (From / To / Date)
- Select flight class (Economy Premium)
- Select passengers (Adults + Children)
- View available flights
- Book flight

### 💳 Payment
- Credit Card payment
- Digital Wallet payment
- Accept Terms & Conditions
- Confirm booking
